# LawPal Frontend

React frontend for LawPal authentication system.

## Setup

1. Install dependencies:
```bash
npm install
```

2. Start development server:
```bash
npm run dev
```

The app will run on http://localhost:3000

## Backend Configuration

Make sure the backend API URL in the pages matches your XAMPP setup. The default is:
`http://localhost/lawpal/lawpal-backend`
